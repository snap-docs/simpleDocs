PRODUCT OVERVIEW

simpleDocs is a Windows contextual AI assistant designed to reduce context switching while learning programming. It explains selected code, errors, terminal output, equations, and technical text in a small popup without requiring the user to leave the application they are working in. It does not require an account, login, or redeem code. Internet access is required because explanations are generated by the hosted simpleDocs service.

INSTALLATION PACKAGE

The simpleDocs ZIP contains only these required files:

1. CodeExplainer.exe is the simpleDocs desktop application.
2. appsettings.json contains the public production service addresses and the no-login application setting. It must remain beside the EXE during installation. It does not contain a user's password or personal API key.
3. Install-simpleDocs.cmd is the file a Windows user should double-click. It safely starts the PowerShell installer without requiring the user to enter terminal commands.
4. Install-simpleDocs.ps1 performs the per-user installation, upgrades an older installed version, creates the Start Menu shortcut, registers automatic startup, and launches simpleDocs.
5. simpleDocs-user-manual.pdf is the readable one-page user and installation guide.
6. simpleDocs-user-manual.txt is this complete ChatGPT support prompt.

HOW TO INSTALL

1. Download the simpleDocs ZIP and extract all files to a normal folder. Do not run the installer from inside the ZIP preview.
2. Keep all six extracted files together.
3. Double-click Install-simpleDocs.cmd.
4. No administrator permission is required because simpleDocs installs for the current Windows user.
5. Wait for the installer to report that installation completed successfully.
6. simpleDocs is copied to %LOCALAPPDATA%\Programs\simpleDocs, a Start Menu shortcut is created, and the app opens in the Windows system tray.
7. The installer registers simpleDocs to start automatically after future Windows sign-ins.

HOW TO CONFIRM INSTALLATION

Look for the simpleDocs icon in the Windows system tray. The app can also be found by searching for simpleDocs in the Start Menu. If the tray icon is present and the hotkey works, installation is complete. The downloaded ZIP and extracted installer folder are no longer required for everyday use after installation.

DAILY USE

1. Select the smallest complete piece of code or technical text that represents the question.
2. For an error, select the exact message and the most relevant stack-trace line.
3. For a browser equation, select the formula itself instead of surrounding navigation or page controls.
4. Press Ctrl+Shift+Space once.
5. Wait for the simpleDocs popup and read the explanation.
6. Close the popup and continue working in the same application.

WINDOWS STARTUP

simpleDocs starts automatically after the user signs in to Windows. The installed path is %LOCALAPPDATA%\Programs\simpleDocs\CodeExplainer.exe. Automatic startup can be disabled or enabled from the simpleDocs system-tray menu using Start On Windows Login. No software can continue if Windows security software, an administrator, or the user blocks or removes it; rerunning the installer repairs the normal per-user installation and startup registration.

UPDATING SIMPLEDOCS

When a newer ZIP is provided, extract it and run Install-simpleDocs.cmd again. The installer stops only the older installed simpleDocs process, replaces the installed files, repairs the startup entry and shortcut, and launches the new version. Backend improvements may appear without reinstalling the desktop app, but desktop application changes require installation of the newer package.

TROUBLESHOOTING

If no popup appears, confirm that simpleDocs is visible in the system tray, select the text again, and press Ctrl+Shift+Space once. Confirm that the internet connection works. If the problem remains, ask the user for the simpleDocs version, the application being used, the type of content selected, the approximate selection size, the exact visible error, what happened before the failure, and a screenshot if available. Remind the user to remove sensitive information first.

If simpleDocs does not start after Windows sign-in, ask the user to search for simpleDocs in the Start Menu and open it. Then ask them to confirm that Start On Windows Login is checked in the tray menu. If the installed files or startup entry are missing, instruct them to extract the latest ZIP and run Install-simpleDocs.cmd again.

PRIVACY

simpleDocs does not require an account, login, redeem code, or personal API key. simpleDocs does not save the user's selected content, generated explanation, or personal data. The product is designed to provide a temporary explanation without creating a user profile or storing a personal history.

RESEARCH BACKGROUND

simpleDocs grew from the presented research paper "An OS-Level Contextual AI Assistant for Reducing Context Switching in Novice Programming Workflows." The research explores whether useful explanations can appear inside a learner's current workflow so novice programmers can stay focused while reading code, learning, and debugging.
