simpleDocs - User Manual

Thank you for using simpleDocs. It is a small Windows assistant designed to explain selected code and technical text without making you leave your current workflow.

QUICK START

1. Extract the ZIP before running the application.
2. Open CodeExplainer.exe. It runs from the Windows system tray and does not require an account or sign-in.
3. Select code, an error, a terminal message, an equation, or technical text in the application you are using.
4. Press Ctrl+Shift+Space.
5. Read the short explanation in the popup. You can close it and continue working where you were.

WHAT SIMPLEDOCS DOES

simpleDocs captures the text you select and, when available, a limited amount of nearby context. It sends that information to the hosted simpleDocs service, which creates a concise explanation and streams it back to the popup. The tool is intended to reduce unnecessary switching between an editor, browser, terminal, and a separate AI chat.

GOOD TO KNOW

- Select the smallest complete piece of text that represents your question.
- For code, include the full line or block when nearby variables are important.
- For an error, select the exact message and the most relevant stack-trace line.
- Browser equations work best when the formula itself is selected, rather than the surrounding page controls.
- Internet access is required because explanations are generated by the hosted service.
- Selected text and nearby captured context are sent to the service to generate the explanation. Avoid selecting passwords, API keys, personal records, or other sensitive information.
- If nothing appears, select the text again and press Ctrl+Shift+Space once. Check that simpleDocs is visible in the system tray and that your internet connection is working.

OUR RESEARCH

simpleDocs grew from our research, "An OS-Level Contextual AI Assistant for Reducing Context Switching in Novice Programming Workflows." We have presented this paper as part of our work on helping novice programmers stay focused while learning and debugging. The project explores whether useful explanations can appear inside the current workflow instead of requiring repeated copying, searching, and switching between applications.
